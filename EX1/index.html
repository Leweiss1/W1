Heap vs stack


In c++, stack is a copile time block of memory that the compiler as the ram to allocate requiment chunk of memory while the heap work differently. The heap is a dynamic allocation that during runtime the code ask the OS to allocate available block of memory and return its address to a stack pointer to hold, this way making new size like array be flexible for when you only need what you use instead of asking for something more than what you need at runtime.
